# Louis Karl Lafata: portfolio

A dark-theme, single-page portfolio built with Next.js, Tailwind CSS and Ant Design.

## Run it

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

`npm run build` makes a production build and `npm run start` serves it.

## Edit the content

All text is in `src/data/profile.ts`, including the LinkedIn link and an empty `email` field. Fill in `email` to show an email button in the contact section.

To change colors, update the values in `src/app/globals.css` (Tailwind) and `src/components/providers.tsx` (Ant Design) together.
